How to make this real: the data below is sample. To wire it to live responses with zero backend — (1) make your pre-event survey a Google Form; (2) it auto-fills a Google Sheet; (3) File → Share → Publish to web → CSV; (4) point this dashboard's fetch() at that CSV URL. Note: this live-fetch works when the file is hosted on a normal web host or opened locally — a claude.ai artifact blocks external fetches, so the published version here always shows sample data. Or simplest of all: just edit the ATTENDEES array at the top of this file by hand before each cohort.
